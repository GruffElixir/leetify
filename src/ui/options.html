Code runner

C++ runs locally by default. Other languages use a Piston-compatible service.

The built-in Clang compiler runs entirely on your computer. No Docker, server, or compiler installation is needed, and local runs never send your code anywhere. Supports standard C++20 and bits/stdc++.h. GNU PBDS, threads, native OS APIs and C++ exceptions aren't supported. Tests have a 2-second execution limit, 256 MiB memory and 256 KiB output. The browser's WebAssembly stack allows only a few thousand nested calls, far fewer than Codeforces. ONLINE_JUDGE is defined, as on Codeforces. Codeforces judging uses its own compiler and limits.

Piston service (optional for C++)

Piston runs send your source and test input to the configured runner. Use a service you trust. Leetify has no built-in hosted runner, account, or telemetry.
