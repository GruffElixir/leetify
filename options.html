Sample runner

Leetify sends code and sample input to this endpoint. The default is a local Piston instance; use a service you trust if you choose another host.

Auto-run waits briefly after an edit and uses the configured runner, so enable it only when you are comfortable sending code automatically.

A custom host needs a one-time Firefox permission grant. The default runner expects Piston at 127.0.0.1:2000.
